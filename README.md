# JustHire – AI-Powered Job Hiring Platform

JustHire is a scalable, real-time job hiring platform designed for Admins, Experts, and Candidates. Built with a modern tech stack, it features intelligent automation, video interviews, role-based dashboards, and accessibility-first design

## Features
- Role-Based Dashboards: Separate, secure interfaces for Admin, Expert, and Candidate roles.
- Real-Time Video Calling: Integrated with WebRTC and Socket.IO for interview sessions.
- Automated Evaluation: Uses Web Speech API for assessing candidate responses.
- Scalable Frontend: Built with React.js + Vite for fast load times and modularity.
- Accessible UI: Designed with accessibility in mind for an inclusive experience.

## Tech Stack

- Frontend: React.js, Vite, Tailwind CSS, JavaScript
- Real-Time Features: WebRTC, Socket.IO
- Speech Processing: Web Speech API
- Database: MongoDB
- Others: HTML5, CSS3
